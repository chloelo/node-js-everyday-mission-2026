## **題目**

> 線上課程平台要記錄以下資料：
> - 每位教練（`coaches`）可以開很多堂課（`courses`），但一堂課只會由一位教練開設。
> - 每位學員（`users`）可以報名很多堂課，一堂課也會有很多學員報名。

請根據以上描述，回答下列問題：

1. 教練與課程是什麼關聯（一對多還是多對多）？如果要用外鍵串起這層關聯，外鍵應該放在 `coaches` 還是 `courses`？為什麼？
2. 學員與課程是什麼關聯？為什麼這層關聯沒辦法只靠在某一張表加一個外鍵欄位來表達？
3. 如果要正確表達「學員報名課程」這層關聯，資料表該怎麼設計？這張表至少需要哪些外鍵欄位、分別指向哪張表？

## 回答

### 1.

教練與課程是**一對多**。

一位教練可以開很多堂課，但一堂課只有一位教練，所以外鍵要放在 `courses`：

`courses.coach_id` → `coaches.id`

因為「多」的那一邊是 `courses`，由課程記住自己是哪位教練開的。

### 2.

學員與課程是**多對多**。

因為一位學員可以報名很多堂課，一堂課也可以有很多學員。

如果只在其中一張表加一個外鍵，只能記住一個對應關係，沒辦法同時記錄多位學員和多堂課之間的關係，所以需要另外建立一張中間表。

### 3.

可以建立一張像 `course_enrollments` 的中間表，用來記錄誰報名了哪一堂課。

至少需要兩個外鍵：

- `user_id` → `users.id`
- `course_id` → `courses.id`

例如：

    course_enrollments
    ------------------
    id
    user_id
    course_id

一筆資料就代表「某位學員報名某一堂課」。

例如：

    user_id = 1, course_id = 3

就是學員 1 報名課程 3。
